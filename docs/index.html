FileMaster is an Android file manager and archive utility built with Kotlin and Jetpack Compose by Ahmedbecetti. The project is actively being developed; features and device compatibility may change.

File management

Browse, search, organize, copy, move, and manage files using Android's document picker.

ZIP tools

Create and extract ZIP archives with safeguards against unsafe archive paths.

Built for Android

A native Android app developed with Kotlin and Jetpack Compose.

FileMaster is a work in progress, not a final production release. Please back up important files and report issues through the project repository.
